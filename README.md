# Dynamic-Restaurant-Workforce-Optimization
Demand-forecast driven shift scheduling for restaurants. FastAPI + scikit-learn hourly demand model (R² 0.958) feeds a MILP roster solver (PuLP/CBC) enforcing rest, hour caps, availability, and role qualification. Argon2id auth with rotating JWT, zero-build dashboard, Docker, CI with SAST/CVE/secret/image scans. 54 tests, 94% coverage.
